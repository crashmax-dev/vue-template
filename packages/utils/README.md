# @vue-workspace/utils

Minimal shared TypeScript utilities package. Built to `dist` with declaration files — use it as the reference shape for other buildable workspace libraries.

Currently exports `double()` as a teaching example used by the playground counter demo.

## Scripts

| Script | Description |
|--------|-------------|
| `pnpm build` | Compile to `dist` |
| `pnpm dev` | `tsc --watch` |
| `pnpm test` | Vitest unit tests |
| `pnpm clean` | Remove `dist` |
